I'm a full-stack engineer. I love UX and the web, and I love backend systems just as much: distributed information systems
and data management. Performance is always the first step to great UX and DX.

## At Elastic

I lead the Documentation Engineering team. We moved the docs from a single monolithic build to a real distributed build
system, and we make sure Elastic's context is ready for agents to consume, agentically and over MCP and APIs. We also built Elastic's public
search and chat interface.

Before that I was the clients tech lead, then the APM tech lead. I love open source initiatives: I led Elastic's move away from
proprietary agents and wire formats to OpenTelemetry. I'm also on the EditorConfig board.

## Languages

I'm not tied to one ecosystem, though I obviously love .NET. I also enjoy Swift, Rust, Go, TypeScript and frontend
development.

With AI, languages matter less, but I find static languages that can express problems succinctly and compile fast to
cross-platform native code a real power boost. Anything that gives AI more guardrails gains productivity.
